# Курс NLP

## Текущий комплект

Готовые материалы находятся в dist/student и dist/teacher. Точка входа — dist/INDEX.html.
Изменения вносятся в обычные папки L01–L08; параллельных редакций для выдачи нет.

Курс содержит восемь лекций, 191 слайд и восемь лабораторных. Все презентации созданы в Figma Slides; полные тексты синхронизированы с ними. Сводка проверки находится в dist/teacher/QA_SUMMARY.md, отчёты — в qa.

## Исходники

- source/lectures, source/plans, source/labs — тексты, планы, задания и код лабораторных.
- source/figma — содержание, storyboard, короткие notes и код создания макетов; Lxx_file.json содержит адрес Figma.
- assets/figma/L01–L08 — экспортированная геометрия окончательных слайдов.
- src/lectureN.ts — конвертация снимка Figma; source/slides — спецификации PowerPoint.
- course — РПД, оценивание и билеты; data — учебные данные.
- scripts — сборка, экспорт и проверка материалов.

Стиль следует выбранному PDF UvA и утверждённым L01/L02: белый фон, Prata, Carlito, линия #1D9A78, крупные обозначения и свободное место. Макеты созданы официальным Figma MCP, затем геометрия SVG переведена в редактируемый PPTX через локальный MCP. Проверяются нативный экспорт Figma, PDF из PowerPoint-файла и полные тексты лекций.

Для проведения занятий команды сборки не требуются. Инструкция для изменения исходников находится в PRESENTATIONS.md.
