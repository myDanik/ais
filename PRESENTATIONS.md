# Редактирование презентаций

Для проведения занятий откройте dist/INDEX.html. Этот документ нужен только для изменения исходников.

Все восемь макетов созданы в Figma Slides. Адрес каждого файла находится в `source/figma/Lxx_file.json` и в оглавлении курса. Содержание и короткие notes хранятся в `Lxx_content.json`, storyboard — в `Lxx_design.md`, а реальные SVG с геометрией — в `assets/figma/Lxx`.

`src/lectureN.ts` вызывает `scripts/figma_to_pptx_spec.py --lesson Lxx`. Конвертер сохраняет расположение объектов Figma и переводит тексты, прямоугольники, таблицы и стрелки в редактируемые элементы PowerPoint. Изображения целых слайдов не используются. Только отдельные криволинейные иконки L01 остаются SVG.

После изменения макета в Figma обновите SVG и нативный PDF, затем пересоберите PPTX и просмотрите его PDF/PNG. После изменения содержания обновите полный текст, видимые подзаголовки переключения, notes и привязки. Проверяется и последовательность объяснения, и сам экспорт.

Оформление следует выбранному PDF UvA и утверждённым первым лекциям: белый фон, Prata для заголовков, Carlito для основного текста, тонкая зелёная линия #1D9A78 и синие подписи источников. Шрифты с лицензиями включены в `assets/fonts`.

## Запуск

Из корня проекта:

```powershell
npm.cmd run build:demo
```

Команда создаёт `output/demo.pptx`, экспортирует `output/demo.pdf` и сохраняет изображения всех слайдов в `output/demo_slides`. Презентация содержит пять слайдов про Mixture of Experts. Часть текста и чисел редактируется прямо в PowerPoint; формула и фрагмент статьи сохранены как графика с исходным TeX и ссылкой на статью.

Для новой презентации создайте storyboard по образцу `papers/new-deck.example.json`, укажите текст лекции, привязки слайдов и выходной путь, затем выполните:

```powershell
npm.cmd run build -- --input papers/new-deck.json
```

Есть компоненты титула, подзаголовка, подписи источника, иллюстрации, фрагмента статьи, формулы, вопроса и раздела. Для предметных схем доступны редактируемые фигуры, текст и стрелки. Их можно задать в `objects` или собрать функциями из `src/components.ts`.

## Что установлено и проверено

Node.js 24.19.0, npm 11.17.0, Python 3.13.14. Node-зависимости закреплены в package-lock.json, Python-зависимости оформления — в requirements.txt. Среда лабораторных описана отдельно в course/requirements-lock.txt.

Работают PptxGenJS, Sharp, resvg, MathJax, PyMuPDF, Pillow и Matplotlib. LibreOffice 26.8.0 и Poppler 26.07.0 находятся в `.tools`; изменение системного PATH для сборки не требуется. ImageMagick не понадобился.

TypeScript сначала компилируется через tsc, затем запускается Node.js. В текущей песочнице tsx не смог получить сведения о профиле Windows, поэтому рабочий запуск использует компиляцию без tsx. Системная политика PowerShell не менялась; шрифт зарегистрирован через стандартный Windows API.

## MCP и проверка

Файл PPTX создаётся локальным MCP-сервером на базе lgwanai/mypoint-mcp и PptxGenJS. Клиент отправляет реальные MCP-команды; журналы находятся в qa. Сервер запускается из скрипта, поэтому переподключение текущей сессии Codex не нужно.

`scripts/render_presentation.py` проверяет границы объектов и текста, заметки и отсутствие отрицательных размеров в DrawingML. Итоговый вид нужно проверять по PNG: автоматическая проверка не оценивает понятность схемы и красоту композиции. Правила оформления и работы со статьями закреплены в SKILL.md.

## Восемь лекций курса

Готовая редакция находится в `dist/INDEX.html`. Для пересборки конкретной презентации:

```powershell
npm.cmd run build -- --deck L05
```

Допустимы L01–L08. Полные тексты находятся в `source/lectures`, сценарии — в `src/lectureN.ts`. После редактирования текста обновите привязки и пересмотрите PNG.

При развёртывании архива исходников сначала выполните `npm.cmd ci`, затем `node scripts/setup_mcp.mjs`. Python и модели подготовьте по START; зарегистрируйте Prata из `assets/fonts/prata`. Для LibreOffice можно задать `LIBREOFFICE_BIN`; если Poppler отсутствует, страницы рендерятся PyMuPDF.
