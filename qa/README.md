# Проверки курса

Текущие рецензии на оформление Figma и перенос в PowerPoint находятся в `L01/figma` — `L08/figma`. Они относятся к конкретным принятым файлам и содержат SHA-256. Здесь же сохранены проверки языка, чисел, переключений слайдов и заметок.

Ранние отчёты в корне папки отражают историю исправлений. Их оценки прежних макетов не заменяют приёмку текущих Figma-презентаций. Готовые материалы выдаются только в обычных папках dist/student и dist/teacher.

Полная сводка приёмки находится в dist/teacher/QA_SUMMARY.md. Проверка файлов — release_integrity.json; проверка архивов — archive_integrity.json. consolidation.json подтверждает, что при удалении старых папок готовые PDF, PPTX, DOCX и ноутбуки сохранены без изменений.
