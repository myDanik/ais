Порядок пяти координат: библиотека, книга, общежитие, оплата, продление. L2 делает единичной длину ненулевого вектора; сумма координат не равна 1. Softmax делает единичной сумму вероятностей. Не присоединять потерю 0,105 к вероятности 0,891: это разные числовые примеры. Изменение веса на 0,1 — вручную заданная демонстрация, а не вычисленный шаг оптимизатора. Вектор (0,8; 0,1) тоже отдельный условный пример, а не полный нормированный TF-IDF-вектор из трёх документов.

Обе модели обучаются на train с `LogisticRegression(C=1, max_iter=1000, random_state=42)`. Words: ngram_range=(1,2); chars: analyzer="char_wb", ngram_range=(3,5); max_features=5000 в обоих. Выбор по validation macro-F1, при равенстве words; повторного fit на train+validation нет. Внутренний критерий обучения — регуляризованная логарифмическая потеря; macro-F1 используется для внешнего выбора.

## Буквальные входы и ошибки

| Полный вход | Предсказание |
|---|---|
| `Не могу найти монографию в списке доступной литературы.` | it |
| `Мне нужна помощь в подборе источников для курсовой.` | it |
| `Мне нужна помощь в подборе источников для курсовой` | study |
| `Здравствуйте! Мне нужна помощь в подборе источников для курсовой.` | study |

Последние три строки подтверждены отдельно при неизменной модели. Конечная точка и пробел после приветствия должны сохраняться в буквальных цитатах. Строка без точки — диагностическая модификация, не дополнительная строка основного test.

Во всех пяти вариантах каждой перечисленной группы предсказание ошибочно: library-19 → 5 it; library-20 → 1 it + 4 study; study-18 → 1 it + 4 library; study-19 → 5 it; study-20 → 5 admission. Все 25 полных строк, их id и предсказания находятся в JSON-свидетельстве. На test recall библиотеки=0,50, учебного процесса=0,25.

Пустая строка и `жжжжжжжжж` имеют 0 ненулевых признаков и получают it; у it максимальное смещение. `Не открывается виртуальная комната конференции` имеет 64 ненулевых признака и также получает it. Это разные механизмы получения одинаковой метки: при x=0 остаётся b; в третьей строке работают и признаки.

## Точность формулировок

1. **Уточнить объяснение `labels`.** В исходном L02-S07 сказано, что без полного списка результат может зависеть от классов, случайно встретившихся среди предсказаний. По умолчанию sklearn берёт объединение `y_true` и `y_pred`: класс без предсказаний всё равно учитывается, если он есть в `y_true`. В этом корпусе все шесть классов есть в каждой части. Точная замена: «Явный список меток фиксирует состав усреднения, даже если какой-то класс отсутствует и среди правильных ответов, и среди предсказаний». `zero_division=0` задаёт поведение при нулевом знаменателе; в примере B с 10 настоящими объектами F1=0 определена через FN=10. [Официальная документация f1_score](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.f1_score.html).
2. **Не сокращать `char_wb` до «только буквы».** Реализация делит по пробельным границам и добавляет пробелы по краям; пунктуация внутри полученного фрагмента сохраняется. Поэтому наблюдаемая чувствительность к точке не противоречит режиму `char_wb`. В JSON сохранён фактический исходник метода из установленной версии. [Официальная документация TfidfVectorizer](https://scikit-learn.org/stable/modules/generated/sklearn.feature_extraction.text.TfidfVectorizer.html).
3. **Не выдавать учебные два score за формат бинарного `decision_function` sklearn.** Расчёт softmax над двумя явно заданными оценками корректен; в лабораторной используется шесть классов. [Официальная документация LogisticRegression](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html).
4. **Устаревшие короткие цитаты в Python.** Преподавательский текст внутри `source/labs/L02.py` опускает точки у library-19/20. В актуальной сборке этот текст заменён JSON-окончанием (`scripts/build_notebooks.py`, ветка `teacher_ending`), поэтому реальный ноутбук и текущая лекция не страдают. При переносе цитат брать точные строки из CSV/JSON-свидетельства.
