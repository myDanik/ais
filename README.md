# Курс NLP

Готовые материалы: [открыть курс](dist/INDEX.html).

- [Для преподавателя](dist/teacher/INDEX.html): полные лекции, планы, презентации, заметки, лабораторные и решения.
- [Для студента](dist/student/INDEX.html): лекции, презентации и задания.

Восемь лекций, восемь лабораторных, 191 слайд. Для просмотра и проведения занятий сборка не нужна.

Все восемь презентаций оформлены в Figma Slides в едином стиле. Ссылки на Figma, PDF и редактируемый PowerPoint находятся в оглавлении курса. Полные тексты содержат точные номера и названия слайдов для переключения во время занятия.

Информация для редактирования исходников находится в [PRESENTATIONS.md](PRESENTATIONS.md).
