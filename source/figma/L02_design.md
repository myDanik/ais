# Вторая лекция в Figma Slides

Файл: https://www.figma.com/slides/t1THZMdu1UfCR5h9udzSV5

Источник содержания: `source/lectures/L02.md`. В лекции 23 видимых подзаголовка; переключение слайда совпадает с началом соответствующего фрагмента. Сначала написан полный текст, затем выбран визуальный способ поддержать каждый фрагмент.

История: знакомые обращения → признаки → обученные коэффициенты → проверка на новых ситуациях → чтение конкретных ошибок. Ручной пример с тремя документами объясняет TF-IDF; двухклассовый расчёт показывает работу оценок и потери. Итоговые метрики относятся к реальному выполнению учебной лабораторной, а не к произвольным данным.

Оформление совпадает с принятой L01: белый фон, Prata Regular для заголовков, Carlito Regular/Bold для текста; зелёный #1D9A78, синий #0070C0 для источников, тёмный #161B18. Кадр 1920×1080, поля144px, заголовок84px, тонкая зелёная линия, основной текст48–72px. Связанные элементы объединяются auto-layout. Минимум декоративных элементов; текст, матрицы, формулы и схемы создаются нативными узлами Figma.
