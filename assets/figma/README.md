# Геометрия презентаций Figma

В папках L01–L08 находятся SVG реальных слайдов Figma с текстом. Адреса файлов Figma сохранены в `source/figma/Lxx_file.json`; полный текст, storyboard и notes находятся рядом в исходниках курса.

`scripts/figma_to_pptx_spec.py` переводит текст, прямоугольники, таблицы и стрелки в редактируемые объекты PowerPoint. Целые слайды не вставляются картинками. Все математические примеры L03–L08 собраны нативными объектами; три криволинейных фрагмента иконок L01 остаются отдельными SVG.

Иконки L01 `door-closed.svg` и `key-round.svg`: [Lucide](https://github.com/lucide-icons/lucide), лицензия ISC. Источник указан на слайде 4.

Числа экспериментов сверены с выполненными лабораторными. Ручные примеры явно обозначены. Независимые отчёты находятся в `qa/Lxx/figma`. Шрифты Prata и Carlito с лицензиями — в `assets/fonts`.
