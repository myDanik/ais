# MCP и инструменты создания презентаций

Для этой редакции выбран и практически проверен локальный [mypoint-mcp](https://github.com/lgwanai/mypoint-mcp), который создаёт PowerPoint через [PptxGenJS](https://github.com/gitbrent/PptxGenJS). Клиент выполняет настоящие операции MCP по stdio: инициализацию, получение списка инструментов, добавление объектов и сохранение файла. Переподключение сессии Codex для этого способа не требуется.

Это запуск сервера из сборочного скрипта, а не заявление о зарегистрированном встроенном инструменте Presentations в интерфейсе. Локальная копия сервера расширена для notes, форматированных фрагментов, фона и параметров фигур. Ревизия upstream: 94cba87b91782c9fbf53bda11ca1f50f8d9c34c3; изменения включены в исходники курса.

Качество обеспечивается подготовкой конкретных слайдов и просмотром результата. MCP даёт операции, а композиция задаётся кодом: отбор тезиса, схема вычисления, крупные обозначения и синхронизация с лекцией. Такой способ позволил воспроизвести выбранный стиль без типового оформления генератора презентаций.

Дополнительно использован [навык pptx из anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/pptx): работа с редактируемыми объектами, проверка файла и визуальная приёмка. Проектный SKILL.md описывает уже работающую процедуру именно этого курса.

При поиске рассматривались также [PowerPoint MCP через COM](https://github.com/Ayushmaniar/powerpoint-mcp), [Figma MCP](https://www.figma.com/mcp-catalog/) и [Canva MCP](https://www.canva.dev/docs/mcp/). Они не проходили здесь сравнительную практическую приёмку. COM-вариант предполагает установленный PowerPoint; внешние редакторы требуют отдельной проверки доступных клиенту операций и итогового экспорта. Для завершения курса они не понадобились.

Gamma исключена по предпочтению автора. Пятислайдовый образец Mixture of Experts и все лекционные презентации создаются тем же локальным процессом. Исходники формул, диаграмм и подписи источников сохраняются для последующей редакции.
